Release Notes – April 2026 / 20.26.04

These release notes describe new features and updates available in the Brightspace April 2026 release. Features roll out progressively across regions according to the Wave Schedule.

General Announcements

New APIs are now available to manage Intelligent Agents across Brightspace. These APIs enable administrators to create, update, and delete Intelligent Agents, which simplifies the management and auditing of agents shared across the organization.

The Danish language pack has been updated to use more accurate terminology. The term elev/elever has been replaced with studerende across all instances in the platform interface.

The Payment Gateway functionality within Course Catalog has reached end of life. No other Course Catalog functionality is affected by this update. Contact your Customer Success Representative for migration guidance.

Courses – Load More increments up to 250 courses at a time

What changed: Administrators can now load up to 250 courses at a time when performing bulk actions. Previously, only 50 courses could be loaded at a time.

Why it matters: This improvement makes it faster to apply bulk actions such as changing course visibility or adjusting start and end dates across a large number of courses.

How to enable: Set the d2l.Tools.Courses.LoadmoreIncrement (OrgUnit) configuration variable in Admin Tools to your preferred increment value, up to a maximum of 250.

Quizzes – Improvements to the Quizzes Evaluation

What changed: The Quizzes Evaluation page has been updated with improved layout and usability enhancements based on feedback from the Product Idea Exchange.

Why it matters: Instructors can now review and grade quiz attempts more efficiently. The updated interface reduces the number of clicks required to navigate between attempts.

How to enable: These improvements are available to all clients and do not require additional configuration.

D2L Lumi Content – Apply HTML templates to multiple pages in bulk

What changed: Authors can now apply HTML templates to multiple pages simultaneously within D2L Lumi Content.

Why it matters: Applying a consistent visual style across a large course used to require updating each page individually. Bulk template application significantly reduces the time needed for course formatting updates.

How to enable: In the D2L Lumi Content editor, select multiple pages and choose Apply Template from the Actions menu.

Rubrics and Assessment APIs – Now stable

What changed: The four existing Rubrics and Assessment APIs are now marked as stable. Previously unstable versions are deprecated. The stable APIs are fully backward-compatible with the earlier unstable routes.

Why it matters: Clients building integrations with Brightspace can now rely on versioned, stable API endpoints for rubric management without requiring changes to existing integration logic.

How to enable: No changes are required for clients already using these APIs. Clients using unstable endpoints are encouraged to migrate to the versioned stable routes.

Learning Outcomes Alignment APIs

What changed: New APIs allow institutions to manage and audit Learning Outcomes alignments at scale. Developers and administrators can now bulk align or remove outcomes from learning activities and retrieve where outcomes are currently aligned across courses, assessments, and content modules.

Why it matters: Reporting on outcomes alignment previously required manual review across individual courses. These new endpoints support retrieving alignments by outcome set, by specific outcome, or across an entire course, with results aggregated to simplify reporting and impact analysis.
