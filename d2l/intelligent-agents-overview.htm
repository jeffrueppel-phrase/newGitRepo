Intelligent Agents Overview

Intelligent Agents are automated rules that monitor learner activity and trigger actions such as sending emails, releasing content, or updating grades. Use Intelligent Agents to provide timely support and personalized feedback without manual intervention.

How Intelligent Agents Work

An Intelligent Agent consists of three components:

  • Criteria: The conditions that must be met to trigger the agent. Criteria can be based on login activity, course activity, or grade thresholds.
  • Schedule: How often the agent checks whether criteria have been met. You can run an agent once, on a recurring schedule, or continuously.
  • Action: What happens when criteria are met. Actions include sending an email to the learner, the instructor, or both.

Creating an Intelligent Agent

To create a new Intelligent Agent:

  1. From the course navigation, click Course Admin.
  2. Under Communication, click Intelligent Agents.
  3. Click New Agent.
  4. Enter an Agent Name and optional description.
  5. Select the Agent is enabled check box to activate the agent immediately.
  6. Under Criteria, choose the conditions that will trigger the agent.
  7. Under Schedule, choose how often the agent runs.
  8. Under Actions, compose the email message that learners will receive.
  9. Click Save and Close.

Note: New APIs are now available to manage Intelligent Agents programmatically. Administrators can use these APIs to create, update, and delete agents across the organization. Refer to the Brightspace Developer Platform documentation for details.

Using Practice Run Mode

Before activating an agent in a live course, use Practice Run mode to test your criteria without sending emails to learners. Practice Run mode shows you which learners would have received an email if the agent had run for real.

To run a practice run:

  1. Open the Intelligent Agent you want to test.
  2. Click Run Now and select Practice Run.
  3. Review the list of learners who meet the current criteria.
  4. Adjust criteria as needed before enabling the agent.

Copying Intelligent Agents Across Courses

You can copy Intelligent Agents to other courses to reuse your configurations. When copying, note that One-Time Run agent schedules are not copied to the destination course. You will need to reconfigure the schedule after copying.

To copy an Intelligent Agent:

  1. On the Intelligent Agents list page, click the drop-down arrow next to the agent name.
  2. Select Copy to Other Courses.
  3. Search for and select the destination course or courses.
  4. Click Copy.

Sending Emails with Replacement Strings

When composing the email message for an Intelligent Agent action, use replacement strings to personalize messages for each learner. Common replacement strings include:

  • {FirstName} – The learner's first name.
  • {LastName} – The learner's last name.
  • {OrgName} – The name of your organization.
  • {CourseName} – The name of the course.
  • {LoginPath} – A direct link to the Brightspace login page.
