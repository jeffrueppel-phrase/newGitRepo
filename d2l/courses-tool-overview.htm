Courses Tool Overview

The Courses tool allows administrators and instructors to create, manage, and organize courses within Brightspace. Learners can use the Courses tool to browse and enroll in available courses.

Accessing the Courses Tool

To open the Courses tool, click Courses on the navigation bar. If the Courses tool is not visible, contact your system administrator to enable it for your organization.

Loading Courses in Bulk

Administrators can load up to 250 courses at a time to perform bulk actions more efficiently. To control how many courses are loaded when you click Load More, configure the d2l.Tools.Courses.LoadmoreIncrement configuration variable in the Admin Tools panel.

Note: Previously, the system allowed administrators to load only 50 courses at a time. The new limit of 250 courses per load enables faster bulk actions, such as changing course visibility or adjusting start and end dates.

Managing Course Visibility

You can show or hide courses from learners at any time. To change course visibility:

  1. Navigate to Admin Tools > Courses.
  2. Select one or more courses using the check boxes.
  3. Click More Actions and select Change Visibility.
  4. Choose Visible or Hidden and click Save.

Setting Course Start and End Dates

Course start and end dates control when learners can access course content. To set dates for multiple courses at once:

  1. Select the courses you want to update.
  2. Click More Actions and select Edit Dates.
  3. Enter the Start Date and End Date for the selected courses.
  4. Click Save to apply your changes.

Creating a New Course

To create a new course using the Courses tool:

  1. Click Create a Course on the Courses page.
  2. Enter a Course Name and Course Code.
  3. Select a Course Template to apply default settings and content.
  4. Set the course Start Date and End Date.
  5. Click Save.

After saving, the course appears in your course list. You can then add content, enroll learners, and configure additional settings.

Enrolling Learners in a Course

Instructors and administrators can enroll learners individually or by importing a list. To enroll learners:

  1. Open the course and navigate to Course Admin > Classlist.
  2. Click Add Participants and select Add existing users.
  3. Search for users by name or email address and select the check boxes next to their names.
  4. Choose a Role from the drop-down list, such as Learner or Instructor.
  5. Click Enroll Selected Users.
